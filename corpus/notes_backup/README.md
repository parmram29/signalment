# Corpus

Atomic notes, one idea per file, validated against `src/signalment/schema.py`.

The four notes here are **schema examples**, not study material. They exist so
the linter and eval harness have something to run against. Replace them with
your own notes; deliberately, none of them contains a numeric dose, because
seeded placeholder content must never be mistakable for clinical guidance.

Run `python -m signalment lint` after adding notes.
